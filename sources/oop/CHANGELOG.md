# Changelog

## 1.0.0

First public release.

- Ctrl+Right-click menu in Ableton Live 12 (Windows): loads VST2/VST3, Ableton devices and Max for Live onto the track under the cursor
- Customizable favorites: drag & drop reordering (multi-selection), separators, submenus via groups
- Plugin picker fed by a real scan of Live's browser
- Light/dark/system theme, tray icon with connection status
- Built-in remote script installer (auto-detects Ableton folders)
- Portable single exe + per-user installer (no admin required)
- Remote script v1.0.1 (Python, UDP on localhost)
